# 杀戮尖塔 · Youdao 词典笔版

一款为有道词典笔（Falcon 运行时）开发的卡牌 roguelike，完整复刻《杀戮尖塔》的爬塔玩法。
打包格式为 `.amr`，全部美术资源均由代码绘制生成，不使用任何 emoji 或外部图片。

## 安装

将 `snjt.amr` 拷入设备后，在终端执行：

```bash
miniapp_cli install <路径>/snjt.amr
```

## 当前版本

v1.6.0（appid `8001111111111111`）

## 游戏内容

| 项目 | 数量 |
| --- | --- |
| 可选角色 | 3（铁甲战士 / 静默猎手 / 故障机器人） |
| 卡牌 | 79 |
| 敌人 | 18 |
| 遗物 | 12 |
| 事件 | 5 |

每个角色拥有独立的初始牌组、初始遗物、专属卡池与战斗机制。

## 玩法

- **爬塔**：12 层分支地图，每层 3～5 个节点，含战斗、精英、商店、篝火、宝箱、事件等类型。
- **战斗**：回合制卡牌战斗，能量 / 抽牌 / 弃牌堆机制，含格挡、虚弱、中毒、易伤等状态。
- **成长**：战后三选一获得卡牌，遗物提供被动效果，篝火可休息回血或升级卡牌。
- **存档**：3 个存档位，支持随时保存与读取。

## 特殊入口

在地图页**连点左上角人物头像 10 次**可进入作弊菜单（无任何提示），提供加生命、加金币与作弊商店。
作弊商店内容与正常商店一致，可购买卡牌、遗物并出售卡牌。

## 牌组页

- 牌组列表支持**上下滑动**查看，超出一屏的卡牌可继续滚动。
- **点击任意卡牌**可在屏幕中央放大查看该卡详情，名称、费用、类型、目标与完整描述均显示在卡面上。
- 再次点击屏幕返回牌组总览。

## 技术要点

- **布局单位**：全部使用 `vw` / `vh` 视口单位，不写死像素值，适配不同屏幕尺寸。
- **视口适配**：启动时读取 `$falcon.env.deviceWidth` 动态调用 `setViewPort`，兼容 X5 Pro（640×260）与 X7（960×266）等不同宽度的机型。
- **滚动容器**：Falcon 运行时仅注册 `scroller` 组件（无 `scroll` / `list`），纵向滚动须写成 `<scroller scrollY="true">`。
- **美术生成**：`tools/art/` 下的纯 Node PNG 编码器绘制全部 92 张图片，不依赖任何外部素材。

